# Structure models

Every `.glb` here is generated by Blender from `blender/generate_structures.py`
and referenced from `public/data/projects.geojson` as
`"modelUrl": "models/<name>.glb"`.

| File | Used for |
| --- | --- |
| `pump-station.glb` | pump houses: apron, intake bay, pump columns, roof monitor, outfall |
| `flood-gate.glb` | tidal flood gate: piers, lifting frames, gate leaves, walkway |
| `drainage-channel.glb` | lined trapezoidal channel with berms |
| `flood-barrier.glb` | dike with crest wall and revetment blocks |
| `sabo-dam.glb` | stepped sediment-control dam and stilling apron |
| `detention-basin.glb` | storage basin with inlet, outlet tower and ramp |
| `dredging-works.glb` | cutter-suction dredger with spuds and floating pipeline |
| `airport-works.glb` | perimeter channel with headwall and outfall gates |

These are **illustrative** structures — a pump house that reads as a pump house
at a glance. They are not engineering drawings of any real facility, and no
dimension in them is taken from a real design.

## Regenerating them

```bash
pip install bpy                              # Blender as a Python module (needs Python 3.11)
python3 blender/generate_structures.py       # all of them
python3 blender/generate_structures.py sabo-dam   # or just one
```

A Blender install works too: `blender --background --python blender/generate_structures.py`.

## Bringing in your own model

```bash
python3 blender/normalise_model.py my-pump.blend pump-station --height 12
```

It accepts `.blend`, `.glb`, `.gltf`, `.fbx`, `.obj` and `.stl`, strips cameras
and lights, applies transforms, moves the origin to the footprint centre at
ground level, optionally rescales to a target height, prints the bounding box
and triangle count, and writes `public/models/<name>.glb`.

## Conventions the app relies on

- **Metres**, **Y up** (the glTF default). The app rotates models into its Z-up
  frame and applies the same scale factor as the placeholder being replaced, so
  a model that is right in metres is right on the map.
- **Origin at the ground contact point**, so the model sits on the basemap.
- **No cameras or lights** in the file — the scene lights it.
- **Keep them light.** These draw over a live basemap; the generated set is
  10–36 kB each. The single-file build inlines them as data URIs, so every
  kilobyte lands in the shared page too.
- A missing or unreadable file leaves the coloured placeholder box in place
  rather than breaking the map.

You can also preview a local file without editing any data: select a project and
use *Import GLB for this project* in the details panel.
